# Тестовые адаптивные шаблоны КП

Все компании и реквизиты вымышлены. Файлы предназначены только для проверки движка.

- `kp_template.docx` — DOCX с маркерами `{{FIELD_NAME}}`.
- `kp_preview.docx` — заполненный пример DOCX.
- `kp_template.pdf` — PDF с именованными AcroForm-полями.
- `kp_preview.pdf` и `kp_preview.png` — заполненное превью.

Поддерживаемые поля перечислены в `manifest.json`.
