# Чеклист ручной проверки

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Войти как `demo` / `demo-pass-123` | Открывается Dashboard |
| 2 | Проверить Dashboard | KPI/таблицы статистики, блок активной отправки |
| 3 | Вкладки статистики | Рассылки / Согласия / Проблемы открываются без ошибок |
| 4 | Создать рассылку | `/campaigns/new`, черновик создаётся и автосохраняется |
| 5 | Выбрать отправителя | Mailpit mailbox выбирается |
| 6 | Отредактировать письмо | Текст сохраняется; в Templates открывается Tiptap |
| 7 | КП шаблон | Выбран/создан шаблон КП |
| 8 | Загрузить получателей | `fixtures/manual/recipients-valid.xlsx` импортируется |
| 9 | Исправить ошибки | Файл с ошибками показывает invalid; дубликаты пропускаются |
| 10 | Настроить пакеты | batch size/interval/limits сохраняются, прогноз виден |
| 11 | Тестовое письмо | Кнопка отправляет письмо |
| 12 | Mailpit | Письмо видно в UI Mailpit |
| 13 | Запуск | Статус running/scheduled, пакеты созданы |
| 14 | Очередь | Вкладка «Очередь» показывает пакеты |
| 15 | Пауза | Новые пакеты не уходят |
| 16 | Продолжить | Отправка возобновляется |
| 17 | Статистика | Счётчики обновляются |
| 18 | Согласие | Сценарий consent → ссылка в письме → confirm |
| 19 | Документы после согласия | Материалы отправляются (если сценарий включён) |
| 20 | Карточка рассылки | Обзор/получатели/очередь/ошибки заполнены |
| 21 | Профиль | Данные сохраняются после reload |
