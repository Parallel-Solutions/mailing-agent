# Описание текущего UI mailing-agent

Документ фиксирует, **как сейчас выглядит и устроено** приложение: визуал, разделы, поля и процессы.  
Новый раздел статистики уже есть и устраивает — **его менять не нужно**, ниже он только упомянут.

Приложение открывается в Docker: `http://localhost:9806`.

---

## 1. Общий визуал

Одностраничное приложение (SPA) в карточке по центру экрана: слева сайдбар (~260px), справа контент шага.

**Стиль**
- Спокойная «зелёная земля»: фон `#f4f5f0`, акцент зелёный `#5a9e1f` / `#3a6e10`
- Мягкие радиальные градиенты (зелёный + янтарь)
- Текст тёмный `#1a1a1a`, приглушённый `#647056`
- Карточка приложения: скругление ~18px, лёгкая тень, рамка оливковая
- Шрифт: Segoe UI / Arial
- Кнопки: primary (зелёный), outline (серая рамка), danger (красная рамка)
- В навигации — цветные точки статуса шага (idle / ok / progress / error)

**Тон**
Пошаговый wizard: «Что нужно на старте?», подсказки «Дальше: …», чеклисты готовности. Не dashboard-first на основном флоу.

**Адаптив**
На узких экранах (<980px) сайдбар сверху, сетки в одну колонку.

Отдельно есть страницы входа/регистрации (белая карточка в том же зелёном стиле) и простые публичные страницы согласия по ссылке из письма.

## 2. Навигация и оболочка

**Сайдбар**
- Заголовок: «Формирование и рассылка коммерческих предложений»
- Блок «Начало»: Настройки
- Блок «Что делаем»: Парсинг → Документы → Отправка писем
- Внизу: имя пользователя, «Очистить поля», «Выйти»
- Два пункта статистики:
  - Статистика отправок (старая) — по текущей сессии/job
  - **Статистика отправок (новая)** — менеджерский кабинет (см. §6)

**Хлебные шаги сверху**  
Настройки → Таблица → Документы → Отправка → Статистика

## 3. Разделы и поля

### 3.1. Настройки — «Подготовить шаблоны»

Чеклист готовности: Письмо · КП · Договор · Тема письма · Отправитель

| Поле / контроль | Тип | Назначение |
|-----------------|-----|------------|
| Вид работ | select | МНГП поселения / районы, СТП МО, Случайный лес, границы терзон и т.п. |
| Название рассылки | text | Имя кампании |
| Что формируем | select | Только КП / КП + договор / Только договор |
| Тема письма | text | Тема для рассылки |
| Подтверждённая почта отправителя | email | From-адрес |
| Шаблон текста письма | file (`.txt` / `.docx`) | Загрузка |
| Шаблон КП | file (`.docx` / `.pdf` / `.html`) | Загрузка (зависит от режима) |
| Шаблон договора | file (`.docx`) | Загрузка (зависит от режима) |

**SMTP-мастер**
- Автоподбор сервера/порта, подсказки, OAuth Google / Microsoft
- Имя отправителя
- При ручной настройке: host, port, SSL, STARTTLS, пароль приложения / SMTP
- Список подключённых ящиков
- Кнопки: «Настроить вручную», «Проверить подключение», «Проверить и сохранить», «Сохранить настройки», «Очистить все поля»
- Переход: «Дальше: загрузить файл или собрать данные»

---

### 3.2. Парсинг — «Загрузить файл или собрать данные»

Два варианта:
1. **Загрузить Excel** (`.xlsx`) → проверка названий МО
2. **Заполнить параметры поиска** → модалка → запуск парсера

**На экране**
- Статус таблицы: прогресс, число строк, badge
- Журнал (чат): сообщения + поле ввода + «Отправить»
- «Дальше: подготовить документы» (когда данные готовы)

**Модалка поиска**
- Что ищем / Где ищем / Объём (+ «Искать всё») / Какие данные нужны
- «Сформировать и отправить»

---

### 3.3. Документы — «Подготовка документов»

**Панель процесса**  
Этапы: Готовим документы → Проверяем текст → Собираем результат; проценты; клиенты / файлы / тексты

**KPI:** Всего клиентов / Готово / Ошибок  

**Режим документов** — только отображение (берётся из настроек)

**Действия**
- «Подготовить документы» / «Остановить»
- Предпросмотр / скачать документы
- Предпросмотр / скачать отчёт филолога
- Чат «Что сейчас происходит»
- Назад / «Дальше: проверить отправку»

**Модалки**
1. AI-проверка шаблона — метрики, плейсхолдеры, PDF-пример, «Запустить массовую генерацию»
2. Предпросмотр документа (iframe)
3. Предпросмотр файла (ZIP / PDF / DOCX / XLSX / текст)

---

### 3.4. Отправка — «Проверить и отправить письма?»

**Этапы:** Проверяем → Ждём подтверждение → Отправляем  

**KPI:** Отправлено / Осталось / Ошибок

| Поле | Значения |
|------|----------|
| Способ отправки | SMTP, UniSender, RuSender, MailoPost |
| Сценарий | Запрос согласия + автоотправка / Сразу материалы |
| Кому | На все почты / Основной + резерв |
| Почтовый ящик SMTP | select |
| Что отправляем | read-only (из режима документов) |
| Запустить позже | checkbox + datetime-local |

**Главная кнопка** (меняется по состоянию):
- «Проверить перед отправкой» → «Отправить письма» → стоп / повтор / «Отправка завершена»
- Перед реальной отправкой — подтверждение в браузере

Дополнительно: предпросмотр/скачивание таблицы и отчёта, отмена расписания, чат, переход к статистике.

---

### 3.5. Статистика отправок (старая)

Упрощённый экран по **текущей** сессии отправки:
- KPI: Отправлено / Ошибка / Не отправлено / Всего + progress
- Опционально: доставка / открытия / клики, заявки на документы
- История «Отправки по дням» (дата, фильтр отправлено / ошибки / все)
- Скачивание таблицы и отчёта текущей отправки

Это не менеджерская аналитика — она в новом разделе ниже.

---

## 4. Процессы (workflows), которые есть сейчас

1. **Настройка сессии** — вид работ, название рассылки, режим документов, тема, шаблоны, SMTP (тест / сохранение / OAuth).
2. **Сбор данных** — загрузка Excel + проверка МО **или** парсер по параметрам / через чат.
3. **Документы** — AI-ревью шаблона → пример → массовая генерация (+ проверка текста / филолог) → архив / скачивание.
4. **Отправка** — dry-run проверка → подтверждение → отправка сразу / по расписанию / сценарий с запросом согласия.
5. **После согласия** — клиент подтверждает по ссылке из письма → автоотправка материалов.
6. **Мониторинг** — старая статистика по job + **новая** менеджерская статистика.
7. **Служебное** — очистка полей, выход, предпросмотры, скачивания, чаты агентов на шагах.

## 6. Новый раздел статистики — уже есть, не трогаем

В сайдбаре: **«Статистика отправок (новая)»** (`#s-statistics`).  
Это встроенный менеджерский кабинет (KPI, воронка, таблицы, графики, отчёты). Визуально согласован с основным UI. **Раздел устраивает — менять его не планируется.**

Кратко, что внутри (для контекста, без предложений по доработке):
- Фильтры: период, рассылка, провайдер, расширенные фильтры, «Обновить»
- Вкладки: Обзор · Рассылки · Компании · Аналитика рассылки · Согласия · Проблемы с email · Отчёты
- Модалки: расширенные фильтры, экспорт, действие менеджера по получателю, карточки/drilldown
